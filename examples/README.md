# Examples

Small projects that use the published `@sweberdev/witness` packages. They show the chatbot notice (Article 50(1)), a visible label on AI-generated content and the machine-readable marking in the page.

| Folder | Stack | Shows |
|---|---|---|
| [`vite`](vite) | Vite, plain TypeScript | `<witness-notice>`, `<witness-label>`, `<witness-player>` and `labelHtml` in the browser |

The examples are not part of the pnpm workspace. Copy a folder, then:

```sh
npm install
npm run dev
```

For React and Next.js see the [React guide](../docs/guides/react.md).

These examples are a starting point, not a compliance check. See [What Article 50 asks](../docs/legal/article-50.md).
